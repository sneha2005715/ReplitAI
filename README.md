# Personal Portfolio Website (HTML + CSS Only)

This repository contains a fully responsive personal portfolio website created using only **HTML and CSS**.  
No frameworks and no external libraries were used.

---

## 📌 Features

### ✔ Required Sections
- Header (Logo + Navbar)
- Hero Section (Headline, Description, CTA)
- Skills Section (6-skill grid)
- Footer (Social Links)

### ✔ Responsive Design
- Desktop → 3-column skills grid, horizontal navbar
- Tablet → 2-column grid
- Mobile → 1-column grid + hamburger menu
- No horizontal scrolling

---

## 🤖 AI Tools Used

To speed up the development, the following AI tools were used:

- **ChatGPT**
- **Cursor AI**
- **Bolt.new**
- **v0.dev**
- **Replit Ghostwriter**

These tools were used to generate initial boilerplate code for:
- HTML layout structure
- CSS grid + flexbox responsiveness
- Mobile navigation toggle logic
- Readability improvements

---

## 🛠 Manual Improvements Made

After generating the initial code with AI, the following manual changes were applied:

### **1. Cleaned the HTML structure**
- Removed extra tags and unused classes
- Improved semantic structure (section, footer, header)

### **2. Corrected CSS responsiveness**
- Ensured proper breakpoints (1023px, 767px)
- Fixed grid layout collapse on mobile
- Removed unnecessary margin causing horizontal scroll

### **3. Improved design consistency**
- Unified padding and font sizes across sections
- Enhanced color scheme and spacing
- Added box-shadow and border-radius for aesthetics

### **4. Added Mobile Hamburger Menu**
- Wrote manual JavaScript toggle function
- Fixed display issues when resizing window

### **5. Ensured W3C HTML + CSS validation compliance**
- Removed deprecated attributes
- Fixed nested tag warnings
